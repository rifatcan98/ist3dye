Merkezi Yapılandırma Motoru

Değişiklikleri Tüm Dünyaya ve Canlı Siteye Aktar

Yönetim panelinde yaptığınız fiyat, malzeme veya vitrin güncellemelerini tek tıkla doğrudan GitHub ve Cloudflare'e gönderin. 15 saniye içinde tüm müşteriler yeni fiyatları ve ürünleri görsün.

Yöntem 1: GitHub API ile Otomatik Yayınla (Önerilen)

GitHub Personal Access Token bilginizi kaydedin, tek tıkla canlıya gönderin.

Token tarayıcınızda güvenle saklanır ve sadece bu deponun data/config.json dosyasını güncellemek için kullanılır.

Yöntem 2: Yapılandırma Dosyası İndir veya Kopyala

Tüm fiyat, malzeme ve vitrin verilerinizi tek bir JSON dosyası olarak yedekleyin.

✓ Yapılandırma panoya kopyalandı!
